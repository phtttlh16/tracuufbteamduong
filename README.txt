TEAM DƯƠNG TRA CỨU — HƯỚNG DẪN ĐĂNG WEB MIỄN PHÍ

1. Đăng nhập https://github.com
2. Nhấn dấu + góc trên bên phải > New repository.
3. Đặt tên repository: team-duong-tra-cuu
4. Chọn Public > Create repository.
5. Trong repository, chọn Add file > Upload files.
6. Tải lên index.html trong gói này (có thể tải cả README.txt).
7. Nhấn Commit changes.
8. Mở Settings > Pages.
9. Ở Build and deployment, chọn Deploy from a branch.
10. Chọn Branch: main, Folder: /(root), nhấn Save.
11. Chờ vài phút. Địa chỉ web sẽ là:
   https://TEN-GITHUB-CUA-BAN.github.io/team-duong-tra-cuu/

Thay TEN-GITHUB-CUA-BAN bằng tên tài khoản GitHub của bạn.

LƯU Ý:
- Đây là giao diện frontend mẫu, chưa có backend và chưa tích hợp các API riêng của fbaio.org.
- GitHub Pages chỉ host website tĩnh HTML/CSS/JS. Muốn API hoạt động thật cần endpoint/backend hợp lệ.
- Không đưa API key, mật khẩu, cookie hoặc dữ liệu nhạy cảm vào mã nguồn công khai.
